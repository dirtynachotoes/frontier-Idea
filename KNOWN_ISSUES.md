# Known limits

The first native remote run 37227359793 compiled successfully but was withheld during artifact audit: MSVC warned that a native mapping literal contained an invalid escape, dropping its Local\ separator. That artifact is NOT installable. The corrected consumer centralizes wide raw names in the portable protocol header, compares actual compiled C++ names with Python, and treats Frontier native warnings as errors. Only the replacement run's complete candidate is valid. The earlier spatial DLL's compile success remains a closed historical gate. Runtime acceptance is still pending.

Guardian Scout Link exports a real native flight lease/pose and uses an NMS walking-assist translation. It does not put a rendered Guardian on NMS terrain, ingest NMS collisions, forward ordinary host movement keys to Guardian flight, transfer damage, implement weapons/abilities, or produce guest-authoritative NMS position yet. Do not describe the 1.25 host assist as authentic Destiny velocity.

Communication runs across activity scripts through existing native hooks. A loaded local Guardian is still required for commands. Background suspension, menu/death transitions and hook availability must be evaluated together in the single final session. Cached packets never renew their own validity. A context change clears the override and requires a new request; persistent user-enabled flight is the restored base preference, so off may legitimately leave base flight enabled.

The old optional Lua phase display remains supported through cached native status, but it no longer owns Sunrise heartbeats or counters. Changed native region ownership and scheduling need final batched acceptance; the historical two-way proof itself is not reopened as an isolated milestone.

Existing NMS positive-nanite callbacks remain a legacy pulse source and may toggle Scout Link while this mode is enabled. No currency integration is added. Disable Scout Link (ordinary Core mode) to retain original region-target-only behavior.

Temporary hover is not persistent progression. Core observations remain transaction-safe in the existing TEST store; lease requests are intentionally not replayed across restart. End-user launcher polish, automatic game orchestration and final DestinyFrontier.exe remain future work.
